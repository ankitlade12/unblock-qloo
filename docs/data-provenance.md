# Data provenance

All bundled data is authored synthetic material. Film titles are identifying references; artwork consists of original CSS shapes rather than film posters. There are no copied provider datasets or downloaded images. No real transport price, accessibility assessment, screening, participant, supplier relationship, or attendance is asserted.

Operational and cultural modes are independent. A future real Qloo response is live at retrieval and recorded when reused. It does not validate fictional events or supplier arrangements. Private evidence includes request parameters, fingerprint, raw provider response, retrieval timestamp, and evidence UUID. Public fixtures never contain Qloo responses. Raw responses are not exported. Cache retention follows the 24-hour workspace lifetime; confirm provider-specific terms with the issued key before a public live demonstration.

Functional requirements are synthetic and entered directly; no diagnosis, income, protected trait, exact address, or requirement is inferred from taste. Only chosen cultural entity IDs enter Insights requests. The optional model receives synthetic context and explicitly invoked tool outputs. Consent can be revoked, removing favorites and recommendations. The existing private evidence stays within the expiring workspace until deletion/expiry; users can delete the entire workspace immediately.

Do not commit `.env`, `data/`, databases, or private provider fixtures. The `.gitignore` and `.dockerignore` exclude these. A repository secret scan and fresh hosted acceptance are required before publication.
